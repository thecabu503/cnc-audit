1.2 ตะกร้ารับงาน * ⚠ ยังไม่ตอบ
1.3 Separetor * ⚠ ยังไม่ตอบ
1.4 Conveyer * ⚠ ยังไม่ตอบ
1.5 Rotary Table * ⚠ ยังไม่ตอบ
1.6 Back Chuck * ⚠ ยังไม่ตอบ

2.เช็คตำแหน่งของสายน้ำมัน Cutting oil ต้องฉีดโดนชิ้นงานเท่านั้น *

⚠ ยังไม่ตอบ

3.มีการลง Information ในเอกสาร PCT เกี่ยวกับรายละเอียดการแก้ไขหรือไม่ *

⚠ ยังไม่ตอบ

4.ตรวจสอบความถูกต้องในการลง Spec ในใบ Inspection Standard Sheet *

⚠ ยังไม่ตอบ

5.มีการแยก Lot No. ของงานระหว่างการแก้ไข ก่อนการแก้ไข และหลังการแก้ไข *

⚠ ยังไม่ตอบ

6.หมายเลข Tool No.และ Counter ของ Tool Lifeใน M/C ตรงกับ Tool Layout ก่อนเปิดเครื่องจักร *

⚠ ยังไม่ตอบ

7.เช็คแรงดัน Bar ตามป้ายที่กำหนด(ลงค่าที่เช็ค) *

⚠ ยังไม่ตอบ

8.การรับงานได้ที่ 100% (เปิดงาน 3 ตัวแล้วตรวจสอบว่างานออกมาครบหรือไม่) *

⚠ ยังไม่ตอบ

9.ตรวจสอบ ปุ่มกด Block skip ต้องมี Cover ปิด (เฉพาะ M/C Type SB-16D-E, SB-20E, SB-23E, SB-32J) *

⚠ ยังไม่ตอบ
